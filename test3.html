My Projects

Continual Learning for Video Segmentation of Surgical Tool

Developed a Domain-Incremental Continual Learning framework for surgical tool segmentation using SAM2 trained with LoRA, enabling privacy-preserving adaptation to challenging surgical scenes. Improved segmentation accuracy by up to 5% using CLIP with K-Means parameter selection, outperforming LwF baselines.

Report

Speech LLM for ASR

Achieved less than 10% Word Error Rate (WER) using self-supervised models like HuBERT and LLMs toperform multi-modal multi-tasking with discrete speech units for Automatic Speech Recognition. Performed continual pretraining and fine-tuning of Large Language Models (LLMs) such as Llama, GPT using QLoRA within Fully Sharded Data Parallel (FSDP) settings, processing∼1 TB of speech and text data to handle Big Data-scale training.

Slides

Spoken Keyword Detection Systems

Built a end-to-end query-by-example spoken keyword detection model (E2E-QBE-SKD) based on a transformer encoder that relies solely on audio for SKD. Enables the model to handle out-of-vocabulary keywords and unseen languages. Trained on 38K keywords from the English split of the MLCommons Multilingual Spoken Words Corpus, achieving 0.8 MTWV.

Report

Schlumberger Hackathon: Summarization Engine

Engineered a FastAPI microservice using TorchServe to run the T5 Transformer model, providing scalable, low-latency abstractive NLP summarization of webpage articles. Implemented LexRank and TextRank algorithms within API pipelines for extractive summarization. The system features keyword generation and employs query-based content filtering using cosine similarity to deliver precise and relevant summaries. Supports multi-threaded web scraping, enabling efficient and concurrent data extraction from various sources for comprehensive article analysis.

Github Finalist Certificate

L&T Hackathon: Surface Crack Detection App

Worked on surface crack detection system using state-of-the-art image classification models such as ResNet and Vision Transformers (ViT) using PyTorch. Integrated image classification model for real-time crack detection, capturing image timestamps, and location information.

Abusive Comment Detection in Low-resource Language

Engaged in developing an abusive comment detection (hate speech) within low-resource NLP contexts in Tamil, leveraging SOTA Transformer Models such as MuRIL and XLM-RoBERTa. Conducted experiments utilizing back translation and lexical replacement for data augmentation. Achieved a 15 unit improvement in macro F1-score.

Yet Another Python Compiler

A Python Compiler, built with Bison and Flex, processes Python code by tokenizing it, parsing it into a syntax tree, and performing semantic checks. It generates intermediate code and applies optimizations like constant folding and dead code elimination. Key features include lexical analysis, syntax and semantic error detection, and code optimization.

Collision Detection Using Quad Trees

Coded a space shooter game in C++ using Quad Tree with HTML, CSS, JS interface for efficient collision detection among large numbers of objects with minimal latency. By organizing objects in a recursive 2D space division, reduces pairwise collision checks, ensuring rapid identification of potential collisions.
